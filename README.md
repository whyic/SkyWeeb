## How to use

- Enhance your discord activity looks with tons of anime icons or hypixel logo and much more!
- To configure it, run ``/rpc`` or ``/skyweeb`` or ``/swrpc``.

The RPC ONLY works while you're inside hypixel skyblock. (more features soon)

## Features


</h1>

- Custom Displays: Freely choose elements to highlight your active profile stats or other customized data.
![primary and secondary line](https://cdn.modrinth.com/data/cached_images/c410e0fd6acc95560055c8dcc6236d8439aa2b1a.png)
- Multi-Element Rotation: Cycle through multiple choices dynamically when you assign more than one element per line.
![rotation lines](https://cdn.modrinth.com/data/cached_images/39f15ffa0efcbb9096cf0904b346e1ea5588e90e.png)
you can drag one element above other for rotation priority.

- Custom Text: 
dont like the preset elements? no worries! you can type in your own custom text to show up on rich presence.
- select the "custom text" option from either primary or secondary line section
![custom textp1](https://cdn.modrinth.com/data/cached_images/e9870fc492dcbb05f30a3430d51971786411f145.png)
- drag it up or wherever you want, you can even keep only element or no element.
![custom textp2](https://cdn.modrinth.com/data/cached_images/b92ecb1b24ad50622ebb3a0d6002237bc47a6e71_0.webp)

### Note: 
- You can only select 1 catergory from anime titles to be active. Thus, select anime category first in:![active series](https://cdn.modrinth.com/data/cached_images/e48643265b73d5190fad22e0292aa058f39e52de.png)

- then choose the icon you want accordingly, whichever character you might want to put on RPC display on discord.
![anime series](https://cdn.modrinth.com/data/cached_images/7867bf3d588dc021d52ab445f984149e97c3964e.png)
- by default, on every series the icons are set to "default" icon of the mod.

- after selecting your icon, you may check the discord activity which now shows your rich presence.
![discord rpc](https://cdn.modrinth.com/data/cached_images/05df581851536e5e4787d5c84e10ad0cc0f1a2f6_0.webp)
